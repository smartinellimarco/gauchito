# gauchito

A Lua API to build your own terminal editor. The binary is `gau`.

## Install

```sh
cargo install gauchito-cli
```

Binaries for macOS arm64 and Linux x86_64/arm64 are on the GitHub releases.
Lua is vendored, nothing else to install.

## Develop

```sh
cargo build --workspace                      # build
cargo run -p gauchito-cli -- [args]          # run gau
cargo test --workspace                       # test
cargo clean                                  # remove build artifacts
cargo fmt --all -- --check                   # check formatting
cargo clippy --workspace --all-targets       # lint
cargo clippy --workspace --fix --allow-dirty && cargo fmt --all   # fix
```

## Release

Every merge to `main` updates a release PR opened by
[release-plz](https://release-plz.dev) with the next version and the
`CHANGELOG.md` entry, both derived from the conventional commit titles.
Merging that PR publishes the crates to crates.io and pushes the `vX.Y.Z` tag;
the tag runs `.github/workflows/release.yml`, which builds the binaries and
creates the GitHub release.

`release.yml` is generated by [dist](https://github.com/axodotdev/cargo-dist)
from `dist-workspace.toml`; do not edit it by hand. Install dist with
`brew install axodotdev/tap/cargo-dist` or `cargo install cargo-dist`.

```sh
dist init       # change the dist settings or update dist, then regenerate the workflow
dist generate   # regenerate the workflow after editing dist-workspace.toml
dist plan       # show what a release would build
```
